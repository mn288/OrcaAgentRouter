What happens next

The panel types agent-router route --b64 … into the terminal you picked. The router grades the prompt, prints every configured route with rule-based reasons, and asks you to pick one. Only then does it run orca terminal create with the harness command and send the prompt unchanged. Nothing is launched from this panel directly; ORCA's plugin panels cannot reach the network and cannot start agents.

LAYA accepts up to 1,000 UTF-8 bytes. The terminal bridge accepts 4,096 characters; longer prompts must be routed with agent-router route --prompt-file.
